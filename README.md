# Mastering XAU/USD

A free, interactive study companion for learning to trade gold (XAUUSD) — built for traders who want a structured, disciplined approach instead of chasing signals or "guaranteed" strategies.

**Live site:** https://anthonypiedt1-byte.github.io/mastering-xauusd/

---

## What's Inside

### 📊 Study Quiz
18 scenario-based questions covering trend filters, entry triggers, risk management, session timing, news filters, and macro drivers (DXY, real yields). Each question uses a drawn chart diagram and gives an explanation tied back to the core framework — not just right/wrong, but *why*. Progress saves automatically, so closing the page mid-quiz won't reset you.

### ✅ Pre-Trade Checklist
Walks through the non-negotiable filters — trend, news, session, risk — before you take a trade. Nothing gets skipped silently. Every check you run gets logged locally, so you can look back and see whether you're actually following your own rules.

### 📖 Study Guide
The core reference material in one place: what to study (price action, key levels, macro drivers), which entries to master (trend-aligned pullback, break-and-retest, liquidity sweep), the non-negotiable filters, a step-by-step guide to marking zones and stacking confluence, and curated free external resources.

---

## Philosophy

Nothing here promises profitability — no tool can. This is built to sharpen two things: **pattern recognition** and **discipline**. The rest — real screen time, backtesting, journaling, and demo trading — has to come from you.

> If a filter fails, there's no trade. A skipped setup costs nothing. A forced trade against a filter is how accounts die.

---

## Tech

Single-file, static HTML — no backend, no build step, no dependencies beyond Google Fonts. Progress and checklist history are stored locally in your browser (`localStorage`), so your data stays on your own device and isn't shared with anyone else using the site.
